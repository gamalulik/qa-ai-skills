# QA AI Skills

Обезличенные версии скиллов для Claude Code, которые я написал и использую в ежедневной работе QA. Внутренние версии привязаны к инфраструктуре проекта (Jira, TestRail, Confluence, тестовые стенды), здесь - шаблоны со структурой и логикой, которые можно адаптировать под свой проект.

*Sanitized templates of the Claude Code skills I built and use daily as a QA engineer. Internal versions are tied to project infrastructure; these are adaptable templates.*

## Скиллы

| Скилл | Что делает | Эффект |
|---|---|---|
| [bug-report](skills/bug-report/SKILL.md) | Перепроверяет дефект на стенде, ищет дубли в Jira, поднимает требования из базы знаний, подбирает поля по моим последним багам и отдаёт готовый черновик тикета | Оформление бага: 20-30 мин → ~5 мин |

Ещё в наборе (внутренние, сюда пока не перенесены): прогон тест-кейсов агентом на стенде с предложением вердикта, приёмка релиза по задачам спринта, приёмка стендов, написание тест-кейсов в TestRail по задаче.

## Принципы, зашитые в каждый скилл

- **Агент ничего не меняет без команды**: Jira, TestRail, сообщения коллегам - только чтение и черновики, исполняю я.
- **Доказательства, а не мнения**: каждый вердикт подтверждается вторым способом (API-ответ, журнал движка, БД).
- **Тест-данные с префиксом** и уборка за собой на стенде.
- **Поля тикетов не из памяти модели**, а из моих свежих тикетов - скилл сам смотрит, как я оформлял похожие баги.
